# [超市清单上的爱情](https://hoo.be/yhsp)

陈明远站在超市货架前，手里攥着一张已经泛黄的购物清单。每周三下午，他都会准时出现在这里，推着那辆有些晃动的购物车，按照清单上的内容一件件挑选商品。

“全麦吐司两包——记得看保质期”“低脂牛奶一升装”“苹果六颗，要红的”“胡萝卜三根，不要太大”...清单上的字迹清秀工整，每条后面还跟着细心叮嘱。这是妻子林小雨五年前写的，那时她刚刚确诊。

“陈老师，又来采购啊？”超市经理老张笑着打招呼，“还是老样子？”

陈明远点点头，小心地将清单对折放回口袋。他今年六十二，退休前是高中历史老师，两鬓已经斑白，但腰杆依然挺直。推着购物车在货架间穿行时，他的动作从容不迫，仿佛在进行某种神圣的仪式。

买完所有物品，他驱车回家——一个位于城西的老式小区。停好车后，他没有立即上楼，而是在小区花园的长椅上坐了一会儿。这是他的习惯，每次采购回来都需要一点时间调整心情。

“我回来了。”推开门，陈明远轻声说道，尽管知道不会有回应。

客厅整洁得过分，阳光透过纱帘在地板上投下斑驳的光影。他把食物分门别类放进冰箱，然后走到书桌前，翻开那本厚重的相册。第一页是他们的结婚照，1979年春天，两人都穿着当时最时髦的衣服，笑容羞涩而灿烂。

“今天超市苹果不错，我挑了六个红的，跟你写的一样。”他对着照片说，手指轻轻抚过妻子年轻的脸庞，“老张问你好，我告诉他你最近在学插花。”

这样的自言自语已经持续了三年八个月，自从林小雨住进养老院后。

五年前，林小雨被诊断出早发性阿尔茨海默症。最初只是偶尔忘记关煤气，后来开始认不出熟悉的路，最后连他也变得陌生。经过两年在家照顾，病情恶化到需要专业护理的程度。

陈明远每周三采购，周六去看她。今天又是周六。

养老院在城郊，环境清幽。他到达时，护工小杨正在给林小雨梳头。

“陈叔叔，今天林阿姨心情不错呢。”小杨轻声说。

陈明远接过梳子，继续为妻子梳理那已经花白但依然柔顺的头发。林小雨安静地坐着，眼神空洞地望着窗外，没有任何反应。

“小雨，春天来了，花园里的玉兰都开了。”他一边梳头，一边轻声细语，“还记得我们院子那棵玉兰吗？你总说它的花瓣像汤匙。”

没有回应。他早已习惯。

每次探视，他都会带些东西——照片、她曾经喜欢的音乐、她最爱吃的桂花糕。护工们都说，林小雨虽然什么都不记得，但陈明远来的时候，她会安静许多。

一个周六的下午，陈明远照常来到养老院。推开房门，却看见林小雨坐在窗边，手里拿着一张纸——是他今早匆忙中落下的超市清单。

他的心猛地一跳。那是她写的清单，五年来，他视若珍宝。

林小雨抬起头，眼中闪过一丝他许久未见的清明。她指着清单，嘴唇微微颤抖：“这...这是我写的字。”

陈明远屏住呼吸，轻轻坐到她身边：“是的，是你写的。我们的购物清单。”

她的手指抚过纸面，像是在触摸遥远的记忆：“全麦吐司...你看，我总在‘吐’字这里多加一点。”她难得地露出一丝微笑。

那一刻，陈明远的眼眶湿润了。五年来第一次，她认出了什么。

“我...我是不是忘了很多事情？”林小雨轻声问，眼神中透露出短暂的清醒。

陈明远握住她的手：“没关系，我记得就够了。”

那天下午，他们像真正重逢的恋人一样聊了很多。虽然大部分时间林小雨还是糊涂的，但那短暂的清醒让陈明远看到了希望。

从那天起，他不再只是简单探视，而是开始有意识地用各种物品唤醒她的记忆——她曾经最喜欢的香水味道、他们蜜月时带回的海螺、恋爱时互写的情书。

效果缓慢但确实存在。林小雨虽然大部分时间仍处于混沌状态，但偶尔会有短暂的清醒时刻。在这些时刻里，她像是从深海中浮出水面，短暂地呼吸记忆的空气。

一个雨天的下午，陈明远正准备离开时，林小雨突然拉住他的衣袖。

“明远，”她清晰地叫出他的名字，眼中含着泪水，“辛苦你了。”

三年多来，这是她第一次完整叫出他的名字。陈明远转过身，紧紧拥抱她，泪水和窗外的雨水一样无法停止。

他知道，疾病可能最终会带走她所有的记忆，但有些东西比记忆更持久——那是融入骨血的习惯，是即使忘记了一切也不会消失的爱。

又一个周三，陈明远站在超市货架前，手里是那张被透明胶带细心粘贴过的清单。他仔细挑选着商品，脸上带着平静的微笑。

因为他知道，即使妻子忘记了如何写清单，忘记了为什么要买低脂牛奶，甚至忘记他是谁，爱本身已经成为一种本能——深深地烙印在他的生命里，如同清单上那些永不褪色的字迹。
